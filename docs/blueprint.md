# **App Name**: Workflow CRM

## Version: 1.0

## Core Features:

*   **User Authentication:** Secure user signup and login. New users require admin approval.
*   **Role-Based Access Control (RBAC):** Granular permissions for different user roles (Super User, Admin, Manager, Viewer).
*   **Dashboard:** A central hub providing a high-level overview of key metrics and activities.
*   **Lead Management:**
    *   **Pipeline View:** Visualize and manage leads in a drag-and-drop Kanban board representing the sales pipeline.
    *   **List View:** A comprehensive, sortable, and filterable table of all leads.
    *   **Lead Detail Page:** A detailed view of each lead, including all associated data and a historical activity timeline.
*   **User Management:** Admins can approve new users, manage existing user roles, and assign users to specific business entities.
*   **Admin Panel:**
    *   **Access Control:** Define and manage permissions for different user roles.
    *   **Appearance:** Customize the CRM's look and feel, including logo and color scheme.
    *   **Entity Management:** Create and manage the business entities or teams within the CRM.
    *   **Pipeline Stage Management:** Customize the stages of the sales pipeline.
    *   **Pipeline Automation:** AI-powered recommendations for optimizing the sales workflow.
*   **AI-Powered "Next Best Action":** Provides users with intelligent suggestions for the next step to take with a specific lead.
*   **Audit Trail:** A complete and searchable log of all significant actions taken within the system for security and compliance.
*   **Help & Documentation:** An integrated section to provide guidance and support to users.


## Style Guidelines:

- Primary color: A deep blue (#3F51B5) evoking trust and stability.
- Background color: Light gray (#F0F2F5), a desaturated hue of the primary.
- Accent color: A vibrant purple (#7E57C2) that contrasts with the primary, providing clear signposts for the most important information.
- Body and headline font: 'Inter', a sans-serif font, for a clean, modern, neutral aesthetic.
- Use flat, minimalist icons to represent different lead stages and actions.
- Employ a responsive layout that adapts seamlessly to different screen sizes, ensuring optimal viewing on desktops, tablets, and smartphones.
- Incorporate subtle animations and transitions to enhance user experience, such as smooth loading indicators and feedback on user interactions.
